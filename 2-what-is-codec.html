What is a Codec? Complete Guide to H.264, H.265, ProRes & RAW

Timeline lag kyun karti hai, export mein time kyun lagta hai, aur editing ke liye kaunsa format sahi hai — sab kuch codec ki wajah se hota hai. Yahaan poori clarity milegi.

By Ajay K MeenaUpdated: July 202610 min read

Bhai, jab bhi koi bolta hai "mera Resolve lag kar raha hai," 9 out of 10 baar problem codec hoti hai, hardware nahi. Toh pehle basics clear karte hain — codec hai kya, aur yeh container se kaise different hai.

Codec vs Container — Sabse Important Distinction

Codec (COder-DECoder) ek algorithm hai jo video data ko compress karta hai record karte time, aur decompress karta hai play/edit karte time. Container (jaise .mp4, .mov, .mxf) sirf ek wrapper/box hai jisme video codec, audio codec, aur metadata sab pack hote hain.

Isiliye ek .mov file mein H.264 bhi ho sakta hai aur ProRes bhi — dono alag codecs hain but container same hai. File extension dekh kar codec guess mat karo, hamesha media info check karo.

Codec Kaam Kaise Karta Hai: I-Frames, P-Frames, B-Frames

Compression ka poora khel frame types pe based hai:

  • I-Frame (Intra/Keyframe): Complete image, apne aap mein poori information hoti hai.
  • P-Frame (Predictive): Sirf pichle frame se jo change hua hai woh store karta hai.
  • B-Frame (Bi-directional): Aage aur peeche dono frames se data leta hai.

Ek P ya B frame play karne ke liye Resolve ko pehle uske pass wale I-frames decode karke reconstruct karna padta hai. Yeh timeline scrubbing ko slow bana deta hai — isiliye phone/camera se seedha H.264 footage pe edit karna laggy feel hota hai.

Codec Ki 3 Main Categories

Long-GOP Delivery Codecs
LOSSY · INTERFRAME

Examples: H.264/AVC, H.265/HEVC, XAVC-S, AVCHD

Yeh camera recording aur online delivery ke liye banaye gaye hain — chhoti file size, achhi visual quality per MB. But editing timeline ke liye heavy hote hain kyunki har frame ko reconstruct karna padta hai.

Advantages

  • Bahut chhoti file size
  • Streaming/delivery ke liye perfect
  • Har device support karta hai

Disadvantages

  • Editing timeline mein laggy
  • Multiple re-export se quality degrade hoti hai
  • Heavy grading mein banding jaldi aati hai (8-bit variants mein)
Intraframe Editing Codecs
MEZZANINE · SMOOTH SCRUBBING

Examples: Apple ProRes (Proxy/LT/422/422HQ/4444), Avid DNxHR/DNxHD, CineForm

Har frame independently complete hoti hai — koi ek dusre pe depend nahi karta. Isse timeline scrubbing instant feel hoti hai. Yeh editing ke liye industry standard hai, delivery ke liye nahi (file size bahut badi hoti hai).

Advantages

  • Smooth, instant timeline scrubbing
  • Better color fidelity, multi-generation safe
  • Higher bit-depth options (10-bit, 12-bit)

Disadvantages

  • File size H.264 se 5-10x zyada
  • Extra storage aur transcode time chahiye
  • Direct camera recording rarely support hota hai (except cinema cameras)
RAW Formats
UNCOMPRESSED SENSOR DATA

Examples: Blackmagic RAW (BRAW), ARRIRAW, RED R3D, CinemaDNG

Yeh actual color image nahi, sensor ka raw photosite data hai — debayering, white balance, aur ISO decisions post-production mein hoti hain, camera mein baked-in nahi. Maximum flexibility milta hai grading mein, but file size aur processing demand sabse zyada hoti hai.

Advantages

  • White balance aur ISO post mein change karne layak
  • Maximum dynamic range preserve hota hai
  • Highest quality ceiling for grading

Disadvantages

  • Massive file sizes (BRAW thoda compressed, ARRIRAW nahi)
  • Debayering ke liye GPU-heavy processing chahiye
  • Sabhi cameras support nahi karte

Editing Workflow Tip: Proxy Strategy

Agar camera se H.264/H.265 footage aa raha hai, seedha timeline pe edit mat karo — laggy hi rahega. DaVinci Resolve mein Generate Optimized Media use karo (DNxHR/ProRes proxy banata hai) ya proxy resolution pe switch karo. Final export ke time original quality automatically use hoti hai.

Pro tip: Proxies ko hamesha SSD pe rakho, HDD pe nahi. HDD ka random-read speed multiple proxy streams ke liye bottleneck ban jaata hai — laggy playback ka yeh bhi ek chhupa hua reason hota hai.

FAQs

Codec aur container mein kya farak hai?

Container (jaise MP4, MOV) ek box hai jo video, audio aur metadata ko pack karta hai. Codec woh algorithm hai jo actual video data ko compress ya decompress karta hai. Ek MOV file mein H.264 ya ProRes dono ho sakte hain.

Editing ke liye H.264 use karna chahiye ya nahi?

H.264 delivery ke liye best hai but editing ke liye heavy hai kyunki long-GOP structure hoti hai. Editing ke liye ProRes ya DNxHR proxies banana better workflow hai.

RAW video kab shoot karna chahiye?

RAW tab shoot karo jab maximum color grading flexibility chahiye ho — commercials, high-end productions. Storage aur processing power zyada chahiye hoti hai isliye har project ke liye zaroori nahi.

Node-Based Color Workflow Seekhna Hai?

Codec samajhna sirf pehla step hai — asli magic Resolve ke Color page pe hota hai. DDR 2.0 mein poora pipeline cover hota hai, camera se lekar final export tak.
