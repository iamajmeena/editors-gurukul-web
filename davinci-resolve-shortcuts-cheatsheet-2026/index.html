DaVinci Resolve Keyboard Shortcuts Cheat Sheet 2026 (Free PDF Download)

Updated for: DaVinci Resolve 21 | Mac & Windows/Linux modifier keys included

Blackmagic Design doesn't publish a single official up-to-date shortcuts PDF for Resolve 21 — only the in-app Keyboard Customization panel (Cmd+Opt+K / Ctrl+Alt+K) and older per-version PDFs. This page compiles the shortcuts that are stable and cross-verified across recent Resolve versions, organized by page, so you can actually memorize them.

4. Fusion Page

5. Fairlight Page

Fairlight has some of the largest gaps in Resolve's default shortcut coverage — most panel toggles, EQ, and AI audio tools have no hotkey by default. Common ones:

6. Switching From Another Editor?

DaVinci Resolve ships two built-in keyboard presets: DaVinci Resolve (default) and DaVinci Resolve Cut (optimized for the Cut page and Speed Editor hardware). You can also import a Premiere Pro, Final Cut Pro 7, or Avid Media Composer keyboard layout from the Keyboard Customization panel (Ctrl/Cmd+Alt/Opt+K) — a huge time-saver if you're switching NLEs.

FAQ

Does Blackmagic publish an official shortcuts PDF for Resolve 21?
No — only older per-version PDFs on their documents server. The in-app Keyboard Customization panel is the only reference guaranteed to match your exact build.

Can I use my old Premiere Pro shortcuts in Resolve?
Yes — Keyboard Customization lets you import a Premiere Pro, FCP7, or Avid preset directly.
