Links Dashboard

Enter your admin password to edit your LinkedIn links page.

One-time setup needed

The dashboard needs a place to save your links. It takes about 2 minutes in Cloudflare.

  1. Cloudflare dashboard, then Storage & Databases, KV, then Create namespace named links.
  2. Open your Pages project, then Settings, Bindings, Add, KV namespace. Variable name: LINKS_KV. Pick the links namespace.
  3. Same place: Variables and Secrets, Add. Name: ADMIN_PASSWORD, type Secret, value is your password.
  4. Redeploy the latest deployment, then reload this page.
